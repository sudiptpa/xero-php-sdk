# Changelog

All notable changes to this package should be documented here.

The format is intentionally simple and human-maintained.

## Unreleased

### Added

- fluent SDK foundation under `Sujip\\Xero`
- OAuth, PKCE, custom connection, tenant, and webhook support
- broad Accounting coverage
- Files, Assets, Projects, Finance, and App Store support
- Payroll AU, NZ, and UK first real slices
- tests, static analysis, parity audit, roadmap, and release checklist docs

### Changed

- docs were tightened to read more directly and less mechanically
- webhook ergonomics were improved with richer payload and event helpers

### Notes

- granular scopes are treated as a first-class concern in both code and docs
- package release prep is tracked in `docs/release-checklist.md`
